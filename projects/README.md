# 重要文抽出と自己修正を用いた日本語要約の出力文字数制御

## 概要

大規模言語モデルは日本語文書要約において高い性能を示す一方，指定された文字数で安定した要約を生成することは依然として困難である．特に日本語では，モデル内部のトークン単位と実際の文字数との不一致により，単純なプロンプト指示や再生成のみでは，正確な出力文字数制御と要約品質の両立が難しい．本稿では，日本語要約タスクを対象として，内容計画情報としての重要文抽出と，出力長や要約品質に着目した段階的自己修正から構成される要約手法を提案する．重要文集合は要約文そのものを固定するものではなく，生成過程における指針として用いられる．提案手法は，初期生成後に文字数制約および内容的妥当性を評価し，必要に応じて修正を行うことで，文字数制約下で生じやすい情報欠落や不自然な表現の抑制を目指す．日本語要約データセットを用いた実験により，文字数指示付きプロンプトや単純な再生成手法と比較して，提案手法が出力文字数制御の安定性を向上させるとともに，要約品質の劣化を抑制できることを示す．
